Download `clip-a-pc.exe` below and run it. It needs no install and no unzipping.

What is new in 0.1.1:

- New Quality setting: 720p at 30 fps (the default) or 1080p at 60 fps. Settings shows
  an estimate of how much memory the choice will use. 1080p60 needs a bigger buffer,
  so long clips use noticeably more memory.

The app updates itself. It checks for a newer release shortly after it starts and
every few hours after that, and checks the download against the published SHA-256
before installing it. You can turn this off in settings.

Windows 11 and a GPU with a hardware H.264 encoder are required.
